# Stilllight Photography

This project is a premium photography portfolio website **Stilllight Photography**, designed to showcase cinematic narratives and artistic visual storytelling.

## Overview

- **Brand Name:** "Stilllight Photography"
- **Service Professionalization:**
  - Cinematic Portraits -> **Cinematic Narrative Portraits**
  - Events & Special Occasions -> **Legacy Event Chronicles**
  - Model Portfolios -> **Professional Persona Portfolios**
  - Landscapes -> **Eternal Vista Photography**
  - Cityscapes -> **Urban Rhythm Chronicles**
  - Places of Worship -> **Sacred Sanctuary Imagery**
  - Flowers and Trees -> **Nature's Fine Art**

## Project Structure

- `index.html`: The centerpiece of the experience, featuring a cinematic banner, about section, and service highlights with immersive animations.
- `layout/`: Contains reusable components including `header.html` and `footer.html` for a consistent navigation experience.
- `css/`: Custom styling architecture:
  - `custom.css` & `css-new.css`: Core design system and premium aesthetics.
  - `bootstrap.css`: Responsive grid foundation.
  - `animate.css`: Pre-defined motion effects.
  - `responsive.css`: Ensuring a seamless experience across all devices.
- `js/`: High-end interactivity layer:
  - `gsap-animation.js` & `ScrollSmoother.min.js`: Advanced cinematic scroll and motion effects.
  - `wow.js`: Triggering animations on scroll.
  - `tilt.query.js`: Interactive 3D tilt effects on portfolio cards.
  - `fancybox.js`: Premium lightbox experience for high-resolution imagery.
- `slick/`: Dedicated assets for smooth, responsive image sliders and carousels.

## Technologies Used

- **HTML5/CSS3:** Semantic structure with high-fidelity, custom-tailored layouts.
- **Bootstrap:** Robust, mobile-first responsive grid system.
- **GSAP (GreenSock):** Industry-leading animation engine for sophisticated, cinematic user journeys.
- **jQuery:** Seamless DOM manipulation and integration of interactive plugins.
- **Slick Carousel:** For dynamic and fluid image showcasing.
- **AOS & WOW.js:** Coordinated scroll-based entrance animations.
- **Fancybox:** Elegant zooming and gallery navigation for photography.

## Installation & Setup

1. Clone the repository to your local machine.
2. Open `index.html` in any modern web browser to view the cinematic experience.
3. No server-side dependencies or build processes are required for the front-end preview.
